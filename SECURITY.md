# Security Policy

## Supported versions

Security fixes are made for the latest released version. Users should update to the latest supported release when one is available.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private **Report a vulnerability** feature on this repository's Security page to contact the maintainers. Include the affected version, impact, reproduction steps, and any safe proof-of-concept needed to verify the report.

If private vulnerability reporting is unavailable for your account, contact the repository owner through GitHub and ask for a private reporting channel. Please allow time for investigation and a coordinated fix before public disclosure.
